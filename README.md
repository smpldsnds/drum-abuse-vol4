# Drum Abuse Vol.4: Digital Drums Boom

Sampling goes mainstream: SP-12, RX-11, DDD-1, LinnDrum tail

Single-shot drum samples from **46 drum machines** released 1984–1985, extracted from the [Synth Abuse Drum Machine Sample Collection](https://www.youtube.com/watch?v=Ay-U9eYKmGA).

- **966 MB** (9050 samples, `.wav`, loops excluded)
- 30 instrument categories: Agogo, Bell, Bongo, Cabasa, Clap, Clave, Click, Conga, Cowbell, Crash, Cuica, Cymbal, FX, Gong, Guiro, Hi-Hat Closed, Hi-Hat Open, Kick, Perc, Ride, Rim, Shaker, Snare, Tambourine, Timbale, Tom, Triangle, Vibraslap, Whistle, Wood Block
- Source: [Drive download](https://drive.google.com/file/d/1eacxX1GtQWqJP3dmZYbYvEPuGtxMtLff/view)
- Thanks to https://www.youtube.com/@synthabuse

## Files in this repo

- `pack.json` — pack metadata
- `index.json` — array of machine summaries
- `instruments/<slug>.json` — flat list of samples per instrument category, across all machines
- `machines/<machine_id>.json` — per-machine detail (sample sets, instruments, sample lists)
- `samples/<machine_id>/...` — the `.wav` files and cover images
